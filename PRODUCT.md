# Atlas

A local, single-user application for a small event team's knowledge catalogue.
Users search and edit metadata, connect documents to datasets and reports, validate event CSVs,
and review AI-assisted metadata proposals before explicit confirmation. Existing data, text,
routes, keyboard controls and backend behaviour are preserved in this design iteration.

The user requests a professional grey, white and black interface, a stronger alternative to
the previous thin default font, and contextual black arrow / hand / text cursors without outlines or shadows.
Success, error and warning feedback keeps green, red and amber respectively.
There is no large pointer-following glow or page overlay. Atlas remains the name.
No publication, remote push, visibility change or deployment without explicit user confirmation.
